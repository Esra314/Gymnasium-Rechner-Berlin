# Gymnasium Rechner Berlin

## Beschreibung

Diese Anwendung berechnet anhand der Noten der 5. und 6. Klasse die Gymnasialempfehlung für Berlin.

## Funktionen

- Vorname und Nachname eingeben
- Noten der 5. Klasse erfassen
- Noten der 6. Klasse erfassen
- Durchschnitt berechnen
- Hauptfachsumme berechnen
- Gymnasialempfehlung anzeigen
- Responsive Design

## Technologien

- HTML
- CSS
- JavaScript
